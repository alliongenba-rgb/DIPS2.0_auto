# PC成果物チェック

3台のPCにある成果物ファイルを、**1つの画面でまとめて検索・確認**するための仕組みです。

```
 PC-01 ─ collect.ps1 ─┐
 PC-02 ─ collect.ps1 ─┼─▶ 共有フォルダ ─▶ viewer.html（ブラウザで検索・確認）
 PC-03 ─ collect.ps1 ─┘    PC-01.csv
   （30分ごとに自動実行）    PC-02.csv
                           PC-03.csv
```

- 各PCを見に行かなくても、「あのファイルはどのPCのどこにあるか」がすぐ分かります。
- 「今日（指定日）に更新されたファイルがないPC」が赤く表示されるので、成果物の出し忘れに気づけます。
- 収集が止まっているPC（電源オフ、タスクの停止など）も「収集遅れ／収集停止」と表示されます。

## ファイル

| ファイル | 役割 |
|---|---|
| `setup.bat` | **これをダブルクリックするだけで初期設定が終わります** |
| `setup.ps1` | 初期設定の本体（コピー、年度フォルダの自動検出、設定作成、自動実行の登録） |
| `collect.ps1` | ファイル一覧を集めて `出力先\PC名.csv` に書き出します |
| `install.ps1` | `collect.ps1` を30分ごとに自動実行するよう登録します |
| `config.json` | 対象フォルダ、年度の下限、出力先の設定（setup が自動で作ります） |
| `viewer.html` | 集めたCSVを読み込んで検索・確認する画面です |

## 対象になるファイル

- 成果物フォルダ（例：`D:\成果物`）の中の **「2006年度」以降の年度フォルダ内にある全ファイル** が対象です。各ソフトが出力する形式（PDF、Excel、写真、ログなど）は問いません。
- 2005年度以前のフォルダは対象外です（`config.json` の `fromYear` で変更できます）。
- `~$` で始まる一時ファイル、`.tmp`、`.bak`、`Thumbs.db` などは除外します。
- 画面では「年度」と「分類（年度フォルダ直下のフォルダ名）」で絞り込めます。

## 導入手順（PC-01 で試す場合）

1. GitHub からZIPをダウンロードします。
   https://github.com/alliongenba-rgb/DIPS2.0_auto/archive/refs/heads/claude/pc-work-automation-system-37g3n6.zip
2. ダウンロードしたZIPを右クリック →「プロパティ」→ 下の「許可する」にチェック →「OK」。
3. ZIPを右クリック →「すべて展開」→「展開」。
4. 展開されたフォルダの中の `pc-check` フォルダを開き、`setup.bat` をダブルクリックします。
   - 青い「WindowsによってPCが保護されました」画面が出たら、「詳細情報」→「実行」。
5. 黒い画面の質問に答えます。
   - 年度フォルダの候補が番号付きで表示されるので、成果物の場所の **番号** を入力してEnter。
   - 出力先は、そのまま **Enter**（`C:\pc-check-share` になります）。
6. 「セットアップ完了」と表示され、確認画面（ブラウザ）が開けば完了です。
7. ブラウザで「共有フォルダを選ぶ」→ `C:\pc-check-share` を選択 →「アップロード」。
   - ファイルがPCの外に送られることはありません。ブラウザ内で読み込むだけです。

以後は30分ごとに自動で一覧が更新されます。確認したいときは `C:\pc-check\viewer.html` を開き、手順7を行います。

### 3台に広げるとき

PC-01 の `C:\pc-check-share` を共有フォルダにして、ほかの2台からは出力先に `\\PC-01\pc-check-share` を指定します（手順5の出力先の質問で入力）。

## よくある質問

- **PCの動作は重くなる？**　ファイル名や日時などの一覧を読むだけなので、通常は数秒で終わります。対象フォルダを広く取りすぎた場合（C:\ 全体など）は時間がかかります。
- **ファイルの中身は送られる？**　送られません。CSVに書かれるのはファイル名・場所・サイズ・日時だけです。
- **止めたいときは？**　PowerShellで `Unregister-ScheduledTask -TaskName PC-Check-Collect` を実行します。
- **実行間隔を変えたいときは？**　PowerShellで `C:\pc-check\install.ps1 -IntervalMinutes 60` のように実行します。
- **成果物の場所を変えたいときは？**　`C:\pc-check\setup.bat` をもう一度ダブルクリックします。
- **自動実行のとき一瞬黒い画面が出る？**　30分に1回、一瞬だけ表示されることがあります。
- **PCを使う人への説明は？**　ファイル一覧を自動で集めていることを、各PCの利用者に事前に伝えておいてください。
