# PC成果物チェック

3台のPCにある成果物ファイルを、**1つの画面でまとめて検索・確認**するための仕組みです。

```
 PC-01 ─ collect.ps1 ─┐
 PC-02 ─ collect.ps1 ─┼─▶ 共有フォルダ ─▶ viewer.html（ブラウザで検索・確認）
 PC-03 ─ collect.ps1 ─┘    PC-01.csv
   （30分ごとに自動実行）    PC-02.csv
                           PC-03.csv
```

- 各PCを見に行かなくても、「あのファイルはどのPCのどこにあるか」がすぐ分かります。
- 「今日（指定日）に更新されたファイルがないPC」が赤く表示されるので、成果物の出し忘れに気づけます。
- 収集が止まっているPC（電源オフ、タスクの停止など）も「収集遅れ／収集停止」と表示されます。

## ファイル

| ファイル | 役割 |
|---|---|
| `config.json` | どのフォルダを、どの種類のファイルを対象にするか、どこへ出力するか |
| `collect.ps1` | ファイル一覧を集めて `共有フォルダ\PC名.csv` に書き出します |
| `install.ps1` | `collect.ps1` を30分ごと＋ログオン時に自動実行するよう登録します |
| `viewer.html` | 集めたCSVを読み込んで、3台分をまとめて検索・確認する画面です |

## 導入手順

### 1. 共有フォルダを作る（1回だけ）

いつも確認に使うPC（例：PC-01）にフォルダを作り、ほかの2台から書き込めるように共有します。

1. 例：`C:\pc-check-share` を作成します。
2. 右クリック →「プロパティ」→「共有」→「詳細な共有」で共有を有効にし、共有名を `pc-check-share` にします。
3. 「アクセス許可」で、3台で使うユーザーに「変更」権限を付けます。
4. ほかのPCのエクスプローラーで `\\PC-01\pc-check-share` が開けることを確認します。

> 共有フォルダの代わりに **Google ドライブ（パソコン版）** の同期フォルダを `outputDir` に指定しても動きます。社外からも見たい場合はこちらが便利です。

### 2. 各PCに設置する（3台それぞれで）

1. `pc-check` フォルダを丸ごと `C:\pc-check` にコピーします。
2. `config.json` をメモ帳で開き、次の項目を編集します。
   - `targets`：成果物を置いているフォルダ。複数指定でき、`%USERPROFILE%` も使えます。
   - `extensions`：対象にする拡張子。空 `[]` にすると全ファイルが対象です。
   - `outputDir`：手順1の共有フォルダ（例：`\\\\PC-01\\pc-check-share`）。JSONでは `\` を `\\` と2つ重ねて書きます。
3. スタートメニューで「PowerShell」を開き、次を実行します。
   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\pc-check\install.ps1
   ```
4. 「○件を書き出しました」と表示され、共有フォルダに `PC名.csv` ができていれば完了です。

### 3. 確認する

1. `viewer.html` をダブルクリックして、ブラウザ（Edge / Chrome）で開きます。
2. 「共有フォルダを選ぶ」で共有フォルダを選択します。CSVをドラッグ＆ドロップしても読み込めます。
3. 使い方：
   - **探す**：検索欄にファイル名やフォルダ名の一部を入力します（例：`熊本 許可`）。
   - **出し忘れを確認する**：期間で「今日更新」または「指定日に更新」を選ぶと、該当ファイルがないPCに「該当なし」と表示されます。
   - **場所を開く**：「コピー」でパスをコピーし、エクスプローラーのアドレス欄に貼り付けます。

## よくある質問

- **PCの動作は重くなる？**　ファイル名や日時などの一覧を読むだけなので、通常は数秒で終わります。対象フォルダを広く取りすぎた場合（C:\ 全体など）は時間がかかります。
- **ファイルの中身は送られる？**　送られません。CSVに書かれるのはファイル名・場所・サイズ・日時だけです。
- **止めたいときは？**　PowerShellで `Unregister-ScheduledTask -TaskName PC-Check-Collect` を実行します。
- **実行間隔を変えたいときは？**　`install.ps1 -IntervalMinutes 60` のように指定して再実行します。
- **PCを使う人への説明は？**　ファイル一覧を自動で集めていることを、各PCの利用者に事前に伝えておいてください。
