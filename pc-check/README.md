# 成果物 格納チェック

作業が完了して、成果物が所定の場所（`N:\01_社内共有\01_案件データ\2026年度\…`）に格納されたことを、
出先の 06 や携帯から **Claude に聞くだけ** で確認するための仕組みです。

```
ALLION-01（30分ごとに自動）                 Notion（保管場所）              あなた（06・携帯の Claude）
 ① 作業経過ログの「完了」行の          →   📦 成果物 格納チェック    ←   「今日の作業、所定の場所に
    成果物の場所に、実際にファイルがあるか      （自動更新）                     格納されてる？」
 ② 2026年度の案件フォルダごとの
    件数・最終更新・今日の更新件数
```

- 人が Notion を開く必要はありません。Claude が 📦 を読んで答えます。
- N: は NAS の共有なので、照合は ALLION-01 の1台で足ります。
- ファイルの中身は読みません。名前・件数・容量・日時だけを見ます。N: の変更・削除はしません。

## 判定の意味

| 判定 | 意味 |
|---|---|
| ✅ 格納済み | 「成果物の場所」に書かれた N: のフォルダ・ファイルが実在し、中身がある |
| ❌ 見つからない | 書かれた場所が N: に無い、またはフォルダはあるが中身が0件 |
| ⚠ 確認できない | 場所が書かれていない／「…」で省略／`\` が抜けている／各PCのローカル（C: D:）で 01 から見えない |
| ➖ 成果物なし | 成果物の場所が「なし」の作業 |
| 📁 今日更新あり／変化なし | 案件フォルダに今日追加・更新されたファイルがあるか |

照合するのは、作業経過ログで「完了」になっていて、直近14日に更新された行です。

## ファイル

| ファイル | 役割 |
|---|---|
| `setup.bat` | ダブルクリックで初期設定（`setup.ps1` を起動） |
| `setup.ps1` | コピー、成果物の場所の確認、Notion の鍵の登録、自動実行の登録、1回目のチェック |
| `check.ps1` | 照合の本体（30分ごとに自動実行）。結果は `C:\pc-check\check.log` にも1行残す |
| `install.ps1` | `check.ps1` を30分ごとに実行するタスク `PC-Check-Collect` を登録 |
| `config.json` | 成果物の場所、年度、除外するもの、Notion のデータベース（setup が作成） |

## 導入手順【ALLION-01で実行】

### 1. Notion の連携用の鍵を作る（1回だけ）

1. ブラウザで https://www.notion.so/profile/integrations を開き、「新しいインテグレーション」を作成します。
   - 名前：`ALLION-01 格納チェック`、ワークスペース：アリオン株式会社、種類：内部
2. 作成後の画面で「内部インテグレーションシークレット」を表示してコピーします（`ntn_` で始まる文字）。
3. アクセス権を付けます。同じ画面の「コンテンツへのアクセス」（Content access）→「アクセス権限を編集」で
   **🖥️ アリオン株式会社 システム管理** を選びます。
   - または Notion で 🖥️ アリオン株式会社 システム管理 を開き、右上の「•••」→「接続」→ `ALLION-01 格納チェック` を追加。
   - 親ページに付ければ、中の 📱 作業経過ログ と 📦 成果物 格納チェック にも効きます。

鍵は ALLION-01 のユーザー環境変数 `ALLION_NOTION_TOKEN` にだけ保存し、Notion やファイルには書きません。

### 2. セットアップ

1. 最新の ZIP をダウンロードして展開します。
   https://github.com/alliongenba-rgb/DIPS2.0_auto/archive/refs/heads/claude/pc-work-automation-system-37g3n6.zip
2. `pc-check` フォルダの `setup.bat` をダブルクリックします。
3. 画面の質問に答えます。
   - 最初の確認（作成するもの）→ Enter
   - 成果物の場所 → そのまま Enter（`N:\01_社内共有\01_案件データ`）→ 一覧を見て Enter
   - Notion の鍵 → 手順1でコピーした鍵を貼り付けて Enter（画面には表示されません）
4. 「セットアップ完了」と、1行のチェック結果（作業ログ照合 ○件（✅ ❌ ⚠ ➖）／案件フォルダ ○件…）が出れば完了です。

## よくある質問

- **止めたいときは？**　PowerShell で `Unregister-ScheduledTask -TaskName PC-Check-Collect` を実行します。
- **01 の電源が切れていたら？**　その間は更新されません。Claude は 📦 の「⏱ 最終チェック」の時刻を見て、いつ時点の情報かを答えます。
- **自動実行のとき一瞬黒い画面が出る？**　30分に1回、一瞬だけ表示されることがあります。
- **前の版で作った `C:\pc-check-share` は？**　もう使いません。削除するかはご判断ください（自動では消しません）。
